# Lyra Mobile

Flutter 客户端用于查看交易账本、持仓、绩效和压力分析，并与一个 Lyra 金融助手对话。AI 由服务端 Genkit 运行，客户端不再选择 Claude、Pi 或 OpenCode，也不使用 MCP。

## 环境与启动

项目基线为 Flutter **3.47.2** / Dart **3.13.2**。完整服务端配置和迁移说明见 [Genkit 与三种账号登录](../../docs/genkit-oauth.md)。

在本目录执行：

```bash
flutter pub get
flutter run --dart-define=LYRA_SERVER_URL=https://lyra.example.com
```

`LYRA_SERVER_URL` 是由开发或发布构建注入的后台地址；上方示例域名必须替换为实际部署地址。首次安装自动使用该配置，用户只选择登录方式，不填写地址、不管理连接。已有安装优先保留凭据绑定和本机记住的原地址，避免升级后进入另一本账本。发布时仍应让 App 和系统浏览器使用同一个可访问的 HTTPS 域名。客户端协议版本为 **3**，需要同步升级服务端：服务端**不再接受协议 2 的客户端**（会返回 426），而协议 3 的客户端也需要协议 3 的服务端。协议 2 时期保存的凭据缺少稳定 `userId`，升级后会被清理并要求重新登录。

客户端仅允许本机回环地址 `localhost`、`127.0.0.1`、`::1` 使用 HTTP；其他地址使用 HTTPS。模拟器的 `10.0.2.2` 不属于回环地址，不接受 `http://10.0.2.2`。真机的 `localhost` 指真机自身，不能用来代指电脑上的服务端。

## 登录与会话

1. 在服务端配置 Google、Linux.do 或 GitHub OAuth 应用即可——**不再需要预先指定允许登录的账号**，新身份首次登录自动注册。回调地址见服务端部署文档。第三方 client secret 始终保留在服务端。
2. 未登录时直接进入独立登录页，只展示 Lyra 品牌与 Google / Linux.do / GitHub 三种方式，不展示财务导航、地址输入或连接管理。后台地址由 App 自动解析，等待读取历史设置后再发现登录方式；无有效地址时不发请求，不要求用户处理技术配置。
3. App 从公开的 `GET /v1/auth/providers` 自动读取三种方式的可用性。只有报告为可用的按钮才能启动授权；其余显示「暂不可用」，读取时提示「正在准备登录…」。目录读取失败或全部不可用时显示一般性的登录提示与「重试」，不透传后台地址、协议或配置消息。目录只表示已配置，不代表真实第三方授权已经联调成功。
4. 点「使用 Google 登录」「使用 Linux.do 登录」或「使用 GitHub 登录」，App 打开系统浏览器提供的 Android Auth Tab。服务端验证结束后，授权窗口自动关闭并返回 Lyra；App 此时才携带 PKCE verifier 兑换凭据，成功后进入工作台，不依赖在浏览器阶段维持后台轮询。关闭授权窗口即取消登录；回到 App 后也可点「取消登录」终止尚未完成的兑换。授权事务最多等待 10 分钟。
5. 在「我的」查看登录方式及邮箱或昵称；Linux.do / GitHub 没有邮箱也能正常登录。退出或失效时清理二级页面并回到独立登录页，普通令牌轮换不会重建导航。退出会先清除本机凭据及 AI 会话 ID，再用捕获的原设备凭据请求服务端撤销；远端撤销失败的消息会保留在新登录页。本机清理失败时提供「重试清除登录」，完成前禁用新的登录操作。

客户端按所选方式严格匹配官方 HTTPS 授权主机与路径，并核对兑换结果的 `user.provider` 和稳定 `subject`；不会把 GitHub 或 Linux.do 的响应当成 Google 身份。访问令牌、刷新令牌、设备私钥和登录主体保存在统一的系统安全存储中。登录交换凭证只存在于内存，跳转 URL 不携带 Lyra 令牌。既有 Google 凭据和 Google subject 偏好键保持兼容；更早的设备配对凭据仍须重新登录。

授权窗口需要支持 Auth Tab 的浏览器（Chrome 137+）。浏览器不可用或版本不支持时明确提示更新或更换浏览器。服务端与 App 必须同步更新：来源登记的 HTTPS 回调地址保持不变，服务端处理回调后统一以 303 跳转到固定的 `com.lyrafinance.lyra://auth/callback`，不携带 code、state、令牌或用户数据。回跳只负责关闭窗口，授权成败仍由兑换接口决定。实现使用 [AndroidX Browser 稳定版 1.10.0](https://developer.android.com/jetpack/androidx/releases/browser) 与 [Android Auth Tab](https://developer.chrome.com/docs/android/custom-tabs/guide-auth-tab)。

「开始分析」会使用当前页面选择的账户范围。已有对话保留自己的账户范围；切换页面账户后，需要点「新对话」才能按新范围分析。流式回答、取消回合、工具结果和服务端会话恢复继续沿用现有交互。迁移前已关闭的旧引擎会话只供查看，需要新建对话继续。

## 添加证券账户与首次导入

「我的 → 证券账户」提供账户列表和新增入口，总览空账本与账户选择器也保留创建入口。填写用于识别的名称、Schwab 文件名中的账户标识和基础币种（默认 USD）。例如 `Individual_XXX276_Transactions.csv` 对应 `XXX276`，无需填写完整券商账号。

也可以先选 CSV / XLSX。导入面板会保留已选文件；没有对应账户时，创建表单会预填文件中的标识，用户确认创建后继续原文件预览。创建证券账户只添加账本归属，交易须在预览页明确确认后才写入。

创建请求响应丢失时，在原表单重试可取回同一次创建结果。重复账户会提示选择已有账户；取消表单会回到导入面板。退出登录或切换身份后，旧请求结果不能写回另一登录会话。

## 我的与常用设置

底部导航为「总览、股票、交易、我的」；宽屏使用同样的四个顶栏入口。「我的」显示紧凑身份区、两组设置卡和文字退出入口。证券账户、启动账户、涨跌配色为一组，行情与估值、关于为另一组；行情来源数量读取服务端实际生效的配置。未登录时使用独立登录页选择账号，已有本机偏好在退出后继续保留。

| 设置 | 默认值 | 生效方式 |
| --- | --- | --- |
| 金额显隐 | 显示 | 总览、股票、交易共用页头眼睛开关，立即切换并记住最近选择，下次启动时恢复 |
| 启动账户 | 记住上次查看 | 可选全部账户或一个活跃账户，下次启动时恢复；改变设置不会切换当前页面或已有 AI 对话 |
| 涨跌配色 | 绿涨红跌 | 可改为红涨绿跌，立即用于金融盈亏文本与图表；正负号、品牌与连接状态色不变 |

金额隐藏覆盖财务页面的金额、价格、费用、期权行权价、原始值提示、辅助阅读文本以及金额图表。数量、笔数、日期和比例继续显示；AI 对话文字不在此开关的处理范围。偏好首次读取完成前先隐藏金额，避免启动时短暂泄露数值；重新显示时仍使用服务端原始十进制数据，不重新计算金融结果。

默认账户与上次查看范围按「规范化服务端地址 + provider + 稳定 subject」隔离；缺少 subject 的旧凭据仅按原设备隔离。启动时重新核对账户是否活跃，原账户不可用则显示全部账户。读取失败时显示可重试状态，不先展示错误账户的金额；用户主动选择优先于迟到的自动恢复。

偏好使用独立的系统安全存储键，以串行读改写保存。保存失败会明确提示，不声称已保存，也不会用默认值覆盖无法读取的设置。退出登录只清除凭据和助手会话引用，本机偏好继续保留。

登录页、总览和「我的」不提供服务器地址或连接管理入口。「关于 Lyra」仅显示已安装 App 的真实版本和 GitHub 项目地址，不显示服务端版本，也不为这些页面发起健康检测。后台地址与部署诊断由开发、发布流程负责，日常用户无需处理。旧凭据自动过期时也会保留原账本地址供重新登录；正常存储后重启仍恢复原地址，偏好写入失败不会阻塞失效凭据的清理。

## 行情与参考估值

打开 **「我的 → 行情与估值」**，在顶部的「行情来源」中为股票和期权分别选择主来源、可选备用来源。每次选择都会自动提交，服务端确认后立即切换，无需保存或取消按钮。主来源选「关闭」时停止该类资产的新行情读取；备用选「不使用备用」时只使用主来源。选择会持久化到服务端，**按当前用户保存**：该用户的全部账户、设备及 Lyra 助手共用，其他用户互不影响，服务重启后恢复；切源本身不需要重启服务。

来源列表由服务端提供，当前适配器为 Alpaca、MarketData。凭据未配置的来源会显示为不可选；API Key、行情模式和请求预算仍在服务器上配置，App 不接收或保存这些密钥。没有持仓、行情关闭或账本读取失败时，来源设置仍可独立使用。新增兼容适配器时，只需扩展服务端目录，App 的选择控件自动显示新来源。

等待服务端确认时显示「正在切换」，暂时禁用来源控件，防止重复提交。确认成功后刷新行情；失败时界面恢复最后已确认的选择并提示重试。其他设备先提交了不同选择时，提示重新加载后再选择，不会静默覆盖对方的设置。关闭面板后，同一登录会话中已提交的切换仍可完成；退出登录或切换身份后，旧结果不能写回新会话。已保存的来源后来缺少凭据或被移除时，保留原选择并提示改选或关闭，不会静默换成另一个来源。详细配置和接口见[行情接入与换源](../../docs/market-data.md)。

股票持仓卡的成本列表下提供紧凑的「参考估值」面板，按币种显示市值和未实现盈亏，展开后可查看参考价、买卖价、选价依据、来源及各自报价时间。来源切换确认后会刷新各账户的行情视图；已发出的旧来源请求不能覆盖新的结果。

金额由服务端以十进制字符串返回，App 不计算价格或期权乘数。行情按完整账户和证券身份与当前持仓匹配；启动账户恢复前不先请求全部账户，切换身份或范围后忽略旧响应。账本版本不一致时提示刷新，报价失败不影响成本列表。

缺价保持 `—`，过期报价明确标注，缺失或过期的币种组不展示完整合计。参考估值按当前持仓与各自报价时点计算，未实现盈亏不含费用；这不是历史组合净值或当日盈亏。金额隐私同时覆盖价格、估值、期权代码里的行权价、Tooltip 和读屏语义。
