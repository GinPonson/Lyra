# Lyra Mobile：已锁定的界面基准

用户于 2026-10-17 明确选定 Genkit 卡片风格，要求固定此方向并推进正式 App。后续界面改动沿用本基准；仅在用户明确调整方向时更新视觉真值。

- 规范：[设计基准](../../docs/plans/lyra-genkit-design-20261017.md)。
- 视觉真值：`../../docs/plans/assets/genkit-20261017/01-overview.png`、`02-stocks.png`、`03-transactions.png`、`04-profile.png`。
- 卡片按语义分组：24 圆角、细灰描边、低反差炭黑表面；内嵌区域 16 圆角。复用统一组件，保持组内列表连续，避免逐条套卡片。
- 总览、股票、交易共用无框账户范围与眼睛开关。搜索和筛选按需展开，刷新用下拉，交易用游标连续加载；页面不显示页码和上一页/下一页。
- 仅保留必要文案；口径说明和次级分析放上下文入口。加载、失败、缺价和来源不可用仍须明确反馈。
- 使用现有 Geist、证券 Logo 和统一线性图标，不使用表情符号。不得把设计稿当背景贴图或把演示数据写入生产。
- 财务按币种分开、保留服务端十进制字符串。已实现损益、净入金、现金余额、历史成本和参考估值含义保持独立。
- 支持窄屏、大字体和减少动画；金额隐藏同时遮住原值、Tooltip、辅助阅读数值与金额图形。
- 验收正式 Flutter 页面及 Android 模拟器，不创建独立 Web 原型。沿用仓库既有业务、登录与错误处理流程。
