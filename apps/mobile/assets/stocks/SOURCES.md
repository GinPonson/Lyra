# 证券标识来源

下载日期：2026-09-12。

PNG 标识来自 Financial Modeling Prep 的公开证券图片端点：
`https://financialmodelingprep.com/image-stock/{ticker}.png`。
文件名对应查询代码，GOOGL 使用 GOOG，BRKB / BRK.B 使用 BRK-B。

这些标识属于各公司或基金的商标，仅用于识别证券，不表示合作或背书。
资源本地打包，应用运行时不向图片服务发送证券代码。
AMZN、NOK、QS 使用深色背景以保留源图的白色图形。

OKLO 使用 Oklo, Inc. 标识（未修改），来源：
