# Sign-in brand assets

These unmodified official assets identify their respective sign-in actions. Preserve their proportions and colors; they are not Lyra logos. All three use a 20 × 20 logical-pixel slot with 12 logical pixels before the button text.

## Google

`google-g.png` is the unmodified Google G logo downloaded from Google's sign-in branding guidelines:

- Asset: https://developers.google.com/static/identity/images/g-logo.png
- Usage guidance: https://developers.google.com/identity/branding-guidelines
- Retrieved: 2026-10-11

Retain the required Google button text and spacing.

## Linux.do

`linuxdo.png` is the original transparent 896 × 896 PNG referenced by the official Linux.do homepage's `og:image` on the retrieval date. The homepage favicon references the same resource hash.

- Source page: https://linux.do/

## GitHub
